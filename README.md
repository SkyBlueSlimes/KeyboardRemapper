# Keyboard Remapper
If you're left handed you probably like using your left hand to maneuver your mouse, but when you try to use it for keyboard and mouse games it becomes a bit tricky.
Keyboard Remapper allows you to save a keybind that toggles between your normal keyboard preset and an entirely remapped keyboard of your choosing.

## Built With:
C# and uses .net 10.0

## To Use

### Requirements:
Currently only works with windows systems. Will likely be flagged as a suspicious software if used while running secure games or applications.
If you are having issues with using the release try downloading net 10.0 for windows.

### Installation:
Download the exe file, preferably to it's own folder because it creates a txt file with it.
Run the executable.

## Usage:
When the program is running, follow the steps on screen and then you will be set up.
To modify or change anything, close and open the executable again and you will be given the prompt to allow you to change the saved information.
